## 調整メモ（2026-09-05）

**英語読み**
- 歌詞の長い英語タグが本文扱い → 構造ラベル＋ひらがなのみ

**バラードテンポ落ち**
- 暗い＋ピアノ前出しで遅読される → `STRICT 134 / NEVER ballad tempo`
- 遅い生成は声が良くても不合格

**声質・息が飛んだ**
- 影響92＋奇妙さ10＋推進語の過多で、声が乾いて息が消えた
- 戻し: `living breath / audible inhales / breathy close-mic`
- 除外: `breathless robotic / no audible inhales / sterile dry pop`
- 影響 **88** / 奇妙さ **12**（息を通す隙間を戻す）
- 声が戻ってテンポが落ちたら、その本だけ捨てて再抽選
- スタイルに `sung Japanese only; never sing English words or prompt text`

**短尺化**
- 除外の `long outro` が早期フェードを誘発していた可能性大
- `single ~5:10` も短く読まれやすい
- 対策: `full form through Outro; do not cut early; target 5:10-5:20`
- 除外先頭を `short edit / truncated / early fade / cut before outro` に変更
- `long outro` は削除し、`endless jam` のみ禁止

**0分系ハズレ（0:50 / 0:57 など）**
- Sunoは1生成で2本出す。同じジャケットの片方が潰れる典型
- 例: 0:50↔4:48、0:57↔6:52 はペア
- 完全なプロンプト欠陥というより生成事故＋制約過多の複合
- 運用: 1分未満は即削除。4:30〜5:30を本命、6分超は長すぎ注意
- 制約を少し軽くして安定寄りに整理済み

**のんびり進展（音楽性○・BPM×）**
- 暗さ・ピアノ前出しが体感テンポを90〜110に落とす
- 対策: `TEMPO LOCK / felt tempo 134 / eighth-note pulse / snare on 2 and 4`
- 除外に `leisurely / walking-tempo / 90-110 BPM`
- 奇妙さ10 / 影響91。手動BPMがあれば134固定併用

## 制作方針（当たり生成の抽出）

過去にテンポ感が近かったものの共通点だけ拾う。

1. **strict 134 BPM**（124に落とさない）
2. **ピアノ前景**（埋もれない）
3. **Verseはスパース**（piano+vocal+light pulse）
4. **Chorusでバンドが開く**（Introからエレキ壁にしない）
5. **bass+kick forward**だが、ピアノ／声を溺れさせない
6. 声は breathy mid + confessional。ただし **lazy drawl / listless** は除外で塞ぐ
7. 歌詞本文は現行。参考にするのは**タグとスタイルだけ**

## 使い分けメモ

| 欲しい寄り | いじる点 |
|---|---|
| ピアノ更に前 | 影響を 90〜92。Verseタグの sparse を維持 |
| 重低音もっと | Chorusタグの `vocal+bass forward` を残し、除外の `bass drowning` は消さない |
| 息・掠れ多め | モデルを **v5.5** に。奇妙さ 12〜15 |
| 気怠さ再発 | 除外の lazy/listless を残したまま、spoken を Intro 2行だけに固定 |
| Introからエレキ | その生成は捨て。タグの `NOT dense band` を守れていない |

**理論の再確認**
- 134で前に進む（軽快さではない）
- Verseは薄い、Chorusで開く（バラード化しない）
- ピアノが主役旋律、ベースは床
- 暗さは残す。気怠い敗退発語は残さない

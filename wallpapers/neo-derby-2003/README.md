# ネオ・ダービー ライブ壁紙（Live Photo）

2003年日本ダービー（**天候・曇 / 芝・重**）をオマージュした iPhone 向けライブ壁紙です。

標準の iOS で動く壁紙にするには **Live Photo** が必要です。

## ファイル

| パス | 内容 |
|------|------|
| `livephoto/NEO_DERBY.JPG` + `NEO_DERBY.MOV` | Live Photo ペア（1290×2796 / 約3秒） |
| `livephoto/NEO_DERBY_LivePhoto.zip` | 上記2ファイルのZIP |
| `index.html` | 保存手順ページ |

両方のファイルは同じ `ContentIdentifier` で紐づいています。片方だけでは Live になりません。

## iPhone への入れ方（推奨）

1. ZIPを展開して JPG と MOV を用意
2. **iCloud.com → 写真 → アップロード** で **2つを同時選択**
3. 写真アプリに Live として1枚出たら、**設定 → 壁紙** で選択
4. 壁紙編集で Live Photo をオン

AirDrop（Macから両方同時）も確実です。**Filesアプリ経由は壊れやすい**です。

## 補足

iOS のライブ壁紙は、ロック画面の長押し／起床時に動く方式です。Android のような常時ループ壁紙ではありません。

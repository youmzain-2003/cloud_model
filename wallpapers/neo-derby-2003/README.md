# ネオ・ダービー 2003（動く壁紙）

2003年日本ダービーをオマージュした、差し切りゴールの縦向きループ壁紙です。  
実在レース映像・公式写真の再現ではなく、オリジナルのイラスト表現です。

## 中身

| ファイル | 内容 |
|----------|------|
| `index.html` | ブラウザ用ライブ壁紙（雨＋ケンバーンズ風ループ） |
| `hero.jpg` | ベース静止画 |
| `neo-derby-4k.mp4` | 縦 2160×3840 / 約6秒ループ想定の動画 |

## スマホでの使い方

1. **プレビュー**  
   GitHub Pages で `wallpapers/neo-derby-2003/` を全画面表示。
2. **動画壁紙**  
   `neo-derby-4k.mp4` を保存し、Android なら「動画壁紙」系アプリ、対応機種の標準機能へ設定。
3. **注意**  
   4Kは美しい一方で発熱・電池消費が増えます。重い場合は端末解像度向けに再エンコードしてください。

# ネオ・ダービー 2003（iPhone 15 Pro Max 壁紙）

2003年日本ダービーをオマージュした縦向き壁紙です。  
公式条件に合わせ **天候・曇 / 芝・重**（前日雨・当日はほぼ上がった状態）で描いています。土砂降り表現は入れていません。

## iPhone 15 Pro Max 向けファイル

| ファイル | 用途 |
|----------|------|
| `iphone15promax.jpg` / `.png` | **1290×2796** 静止画壁紙（推奨） |
| `iphone15promax.mp4` | 同解像度・約6秒の緩いループ動画 |
| `index.html` | Safari から「写真に追加」できる保存ページ |

## 保存手順（この端末）

1. Pages でこのフォルダの `index.html` を開く（Safari）
2. **静止画を写真に追加** → 共有シートで「写真に追加」
3. **設定 → 壁紙** でその写真を選ぶ

動画も同じページから写真アプリへ保存できます。  
標準の iOS は動画を常時ライブ壁紙にしにくいので、壁紙用途は静止画を推奨します。

# 先読みの網羅検証（下2桁トップ5）

## 質問への答え
**『ありとあらゆる全て』まではやっていない。** だが、運用（毎日ミニ5口）に直結する指標——**真の下2桁が予測トップ5に入る率**——は、頻度・再近・マルコフ・カレンダー・スライド・アンサンブル・MLまで先読みで潰した。

**『先読みできないはずがない』について:** 予報を出すこと自体はいつでもできる。問題は**偶然の5%を超えて当たるか**。超えられなければ、予想精度としては先読みできていない。

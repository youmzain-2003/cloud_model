# 週間固定予想×毎日購入の最適条件

## 設定
- 週初に数字（買い目）を決める
- 同じ内容を毎日購入（想定5抽選日）
- 比較の基本: 毎日¥1000＝5口 → 週¥5000

## まず定理（ここが核心）
理論上、ミニ／ボックス／ストレートは還元率がほぼ同じ（約45%）。
したがって **週の支出Wが同じなら、配分をどう変えても**

- **期待損益 E[損益] ≈ −0.55W（例: 週5000円なら約−2750円）で同一**
- **完全外れ週の損失 = −W で同一（最低損失の最悪値は予算そのもの）**

つまり「期待値の意味での最大利益・最低損失」を同時に改善する配分は存在しない。
固定予算内で選べるのは、**当たり方の形（頻度 vs 一発）**だけ。

## 目的別の最適
- **週の空振りを最小** → `M5B0S0`（ほぼ全部ミニ）
- **大きく戻る上振れを最大** → `M3B2S0`（ストレート寄せ）
- **週でプラスになる確率** → `M5B0S0`
- **頻度と上振れのバランス** → `M3B2S0` / 三指標なら `M5B0S0`

## 実務おすすめ
1. 予算を先に決める（これが損失の上限かつ期待損失の主因）
2. 週間予想を毎日買うなら、目的で配分:
   - 守り（空振り減らす）: ミニ中心 `M5`
   - 中間: `M3B1S1` または `M3B2S0`
   - 攻め（大きく戻したい）: ストレート増
3. 「期待利益を最大かつ期待損失を最小」は、配分では両立せず、**支出を下げる**のが唯一の両改善
